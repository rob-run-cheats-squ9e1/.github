## What it does

Rob Run is a fast-paced, action-packed game where you play as a robot named Rob. Your goal is to navigate through various levels, collect items, and defeat enemies to progress. The game features a unique combat system that requires quick reflexes and strategic planning.

The most frustrating aspect of Rob Run is the lack of health regeneration and the need to constantly manage your health bar. This trainer addresses that by providing options to increase your health and speed up the game, making it more enjoyable and less stressful.

## Features

| Option | Hotkey | What it does |
|---|---|---|
| Infinite Health | `F1` | Gives Rob unlimited health |
| Speed Boost | `F2` | Increases Rob's movement speed |
| Unlock All | `F3` | Unlocks all levels and items |
| Free Camera | `F10` | Allows you to view the game from any angle |
| Hide HUD | `F11` | Hides the heads-up display for screenshots |

<sub>Tags — **`comfort`**: accessibility, changes nothing. Use at most three. Anything tagged `bypass` or `spoiler` ships off.</sub>

## Hotkeys

`Insert` opens the menu · `End` resets everything · `F1`–`F12` as above, all rebindable · arrow keys and `Enter` navigate without a mouse

> [!TIP]
> Set Infinite Health to on and Speed Boost to 3x for the best balance of challenge and convenience. This combination keeps the game fun and engaging while making it more accessible. The combat system remains intact, so you still need to use strategy and quick reflexes.

> [!WARNING]
> Unlock All removes the need to progress through the game linearly and can make the game feel too easy. This option is best used for speedrunning or exploring the game's content.

<details>
<summary>Does it work on Steam Deck or Linux?</summary>
No. Windows only. Proton changes how the game's memory is laid out and this build does not handle that.
</details>

<details>
<summary>Windows Defender flagged the download.</summary>
Trainers read and write another process's memory, which is what a lot of malware also does, so heuristic scanners flag them on principle. Every release ships with a SHA256 checksum and full source. Add an exclusion if you are comfortable with that — and if you would rather not, don't. That is a reasonable call.
</details>

<details>
<summary>Options stopped working after an update.</summary>
Patches move memory offsets and options fail independently, so some will keep working. Check the Releases page for a build matching your game version.
</details>

## Troubleshooting

| Symptom | Fix |
|---|---|
| Nothing happens on `Insert` | Another overlay grabbed the key — Steam, Discord or RTSS. Rebind the menu key. |
| "Process not found" | The game must be running with a save loaded. Launch it first, then attach. |
| Unlocks vanished after a patch | A persistent write was invalidated. Restore a backup from before the update. |
